### 🧭 Tentang Saya

Berkarier di dunia **kreatif** — desain grafis, motion graphics, videografi, dan fotografi — kini bertransformasi menjadi **full-stack developer**. Latar belakang visual itu membentuk cara saya membangun aplikasi: fungsional, tapi tetap enak dilihat dan nyaman dipakai.

Perjalanan coding saya dimulai dari bangku SMK (TKJ), dan sekarang saya membangun aplikasi web yang benar-benar dipakai sekolah saya — dari sistem e-learning sampai event nasional.

- 🔭 Sedang mengerjakan: **E-Learning TKJ** (CodeIgniter 4 + React) & **MPJ Fest** (Laravel + React)
- 🎨 Fondasi: graphic design, motion graphics, videography, photography
- 🌱 Sedang mendalami: web full-stack, deployment, dan backend architecture
- 📍 Domisili: Kota Blitar, Jawa Timur, Indonesia
